# Third-party software and assets

This branch contains only the material editor and the source files it requires.

## Build-time dependencies

- [Dear ImGui](https://github.com/ocornut/imgui) — MIT license, fetched at build time (pinned to v1.92.9b-docking).
- [GLFW](https://github.com/glfw/glfw) — zlib/libpng license, fetched at build time (pinned to 3.4).
- [GLAD](https://github.com/Dav1dde/glad) — generated OpenGL loader checked into `glad/`; the Khronos `khrplatform.h` retains its copyright and permission notice in the file.
- [Poly Haven](https://polyhaven.com/license) — CC0 photographic studio, outdoor and night panoramas converted and bundled as compact preview images at build time.
